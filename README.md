# 📖 Sobre o Projeto

O **Painel Administrativo AutoNova** é a aplicação utilizada exclusivamente pela equipe administradora da plataforma.

Seu objetivo é fornecer uma interface moderna, organizada e escalável para controlar toda a operação do sistema, centralizando os módulos administrativos em um único ambiente.

Este painel **não é destinado aos clientes finais**.

# 🚀 Inicializando o Projeto

Instale todas as dependências:

```bash
pnpm install
```

Execute em modo desenvolvimento:

```bash
pnpm dev
```

Gerar build de produção:

```bash
pnpm build
```

Verificar erros do TypeScript:

```bash
pnpm exec tsc --noEmit
```
